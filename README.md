# 🚜 AgriRental Hub

> **Rent the right equipment. Farm smarter.**

**AgriRental Hub** is a modern agricultural equipment rental platform designed to make farming machinery more accessible and affordable for farmers.

Instead of purchasing expensive agricultural equipment, farmers can discover, compare, and rent the machinery they need for specific farming activities. From tractors and harvesters to tillers, seeders, sprayers, and other agricultural tools, AgriRental Hub connects farmers with the equipment they need when they need it.

## 🌾 Why AgriRental Hub?

Agricultural machinery can be expensive to purchase and maintain, especially for small and medium-sized farmers. AgriRental Hub provides a flexible alternative by enabling farmers to rent equipment without the large upfront investment of ownership.

### Key Benefits

- 💰 **Reduce Equipment Costs** — Rent machinery instead of purchasing expensive equipment.
- 🚜 **Access Modern Machinery** — Get access to a wide range of agricultural equipment.
- ⏱️ **Save Time** — Find the right equipment quickly for specific farming activities.
- 🌱 **Farm More Efficiently** — Use specialized machinery to improve productivity.
- 📍 **Easy Discovery** — Browse available equipment based on farming needs and location.
- 📅 **Flexible Rentals** — Rent equipment for the period you actually need it.

## ✨ Features

### 👨‍🌾 For Farmers

- Browse agricultural equipment
- Search and filter machinery
- View equipment details and specifications
- Check rental pricing and availability
- Request or book equipment
- Manage rental bookings
- View booking history
- Save preferred equipment

AgriRental Hub can support a wide range of agricultural machinery, including:

- Tractors

- Tillers
- Seeders
- Sprayers
- Ploughing equipment

- Irrigation equipment

- Other agricultural tools and machinery

### 🏪 For Equipment Owners

Equipment owners can:

- List agricultural machinery
- Add equipment specifications and images
- Set rental prices
- Manage availability
- Receive rental requests
- Manage active and completed rentals

## 🎯 Mission

The mission of AgriRental Hub is to make agricultural technology more accessible by creating a convenient rental ecosystem for farmers and equipment owners.

By reducing the need for large equipment investments, the platform helps farmers access the machinery they need while improving the utilization of existing agricultural equipment.

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd agrirental-hub
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser at the local development address provided by the framework.
